# 할 일 목록 앱
[한국어](README-ko.md) | [English](README.md)

HTML, CSS 및 JavaScript를 사용하여 구현한 간단한 할 일 목록 애플리케이션입니다. 사용자가 할 일 목록에서 작업을 추가, 편집 및 삭제할 수 있습니다.

## 기능
- 목록에 새 작업 추가
- 기존 작업 편집
- 목록에서 작업 삭제
- 작업을 완료로 표시
- 모바일 및 데스크톱 장치에 대한 반응형 디자인
- localStorage를 사용하여 지속적인 저장, 페이지를 새로 고쳐도 작업이 저장됩니다.

## 사용 방법
1. 저장소를 클론하거나 소스 코드를 다운로드합니다.
2. `npm install` 명령을 사용하여 필요한 종속성을 설치합니다.
3. `npm run dev` 명령을 사용하여 개발 서버를 시작합니다.
4. VITE에서 나타나는 `Local: https://localhost:5173/` 링크를 클릭합니다.
5. 입력 필드를 사용하여 새 작업을 추가하고 "Add" 버튼을 클릭합니다.
6. 작업을 클릭하여 편집하고 "Delete" 버튼을 클릭하여 목록에서 제거합니다.
7. 작업 옆의 체크박스를 클릭하여 완료로 표시합니다.
8. 작업은 브라우저의 localStorage에 자동으로 저장됩니다.
